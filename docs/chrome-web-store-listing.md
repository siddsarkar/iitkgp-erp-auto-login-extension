## Description

```
ERP Auto Login - IITKGP automatically fills your credentials on the
IIT Kharagpur ERP website (erp.iitkgp.ac.in) and logs you in.

Features:

• Automatic ERP login and autofill
• Works with the ERP's OTP login flow (the form is filled, you click "Send OTP")
• Optional 4-digit PIN protection; credentials are encrypted when a PIN is set
• Local credential storage
• Quick links to ERP modules (Home, Academic, CDC, Guest House)
• Configurable landing page after login
• Light and dark themes
• Open-source implementation

Privacy:

Credentials are stored locally in the browser using the extension storage
API. The extension does not send credentials to any external server. It only
communicates with erp.iitkgp.ac.in.

Permissions:

• storage - to keep your credentials and preferences in the browser
• erp.iitkgp.ac.in - to fill the login form and sign you in

The extension is intended for IIT Kharagpur students. It is an independent
open-source project and is not affiliated with or endorsed by IIT Kharagpur.

Source code: https://github.com/siddsarkar/iitkgp-erp-auto-login-extension
```
